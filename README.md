# Machine Learning and Deep Learning Projects

A collection of machine learning coursework and practical projects developed as part of the Computer Engineering degree at the University of Granada (UGR).

This repository explores supervised learning, unsupervised learning, and deep learning through Jupyter notebooks, including a chatbot project implemented using deep learning techniques.

## Projects

### 1. Supervised Learning
**Notebook:** [`P1-Aprendizaje-supervisado.ipynb`](P1-Aprendizaje-supervisado.ipynb)

Practical work on supervised machine learning, focusing on learning from labelled data to solve prediction tasks.

### 2. Unsupervised Learning
**Notebook:** [`P2-Aprendizaje-No-Supervisado.ipynb`](P2-Aprendizaje-No-Supervisado.ipynb)

Practical work exploring unsupervised learning approaches for analysing data without predefined target labels.

### 3. Deep Learning
**Notebook:** [`P3-Deep-Learning.ipynb`](P3-Deep-Learning.ipynb)

Practical exercises covering deep learning concepts and neural-network-based approaches.

### 4. Deep Learning Chatbot
**Notebook:** [`Chatbot-con-Deep-Learning.ipynb`](Chatbot-con-Deep-Learning.ipynb)

A chatbot project implemented using deep learning. The notebook contains the implementation and experimentation workflow.

## Technologies

- Python
- Jupyter Notebook
- Machine Learning
- Deep Learning

The specific libraries and algorithms used are documented in the corresponding notebooks.

## Getting Started

Clone the repository:

```bash
git clone https://github.com/paulaa7/Aprendizaje-automatico.git
cd Aprendizaje-automatico
```

Install Jupyter Notebook or use an environment such as JupyterLab or Google Colab to open the notebooks.

Review each notebook for its specific dependencies and setup requirements before execution.

## Learning Objectives

- Explore supervised and unsupervised machine learning approaches.
- Practise implementing and analysing machine learning workflows.
- Develop practical experience with deep learning.
- Apply deep learning techniques to a conversational application.

Developed as part of the Machine Learning coursework in the Computer Engineering degree at the University of Granada.
